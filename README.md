# Портфолио Данила Яроша

Портфолио открывается как полноэкранная 3D-выставка на Three.js. Восемь проектов представлены отдельными моделями: игровые автоматы, разменник, рабочие станции, LED-панель, сцена с чародеем и палитры тем. Объекты можно выбирать нажатием, приближать, рассматривать и оживлять кнопкой в описании. Сайт публикуется на GitHub Pages и переносится на любой хостинг статических файлов.

## Разработка

Нужен Node.js 22.12+ или 24 LTS.

~~~sh
npm ci
npm run dev
~~~

## Сборка и публикация

~~~sh
npm run build
~~~

Готовый сайт находится в dist/ и автоматически копируется в docs/. В репозитории GitHub Pages настроен на ветку main, папку /docs. Для обновления выполните сборку, затем commit и push. Исходники, package-lock.json и готовая папка docs хранятся вместе; node_modules и dist в Git не включаются.

## Как редактировать

- src/projects.js — карточки, технологии, описания и ссылки на проекты.
- index.html — главная страница, сведения об авторе и контактные ссылки.
- src/style.css — оформление и адаптивная компоновка.
- src/world.js — 3D-выставка, модели, камера, выбор объектов и интерактивные эффекты.
- public/assets/ — изображения и сведения о лицензиях.

## Перенос на другой хостинг

Выполните npm ci и npm run build, затем загрузите содержимое dist/ в публичную папку сайта. Node.js на сервере не нужен. Ресурсы используют относительные пути; серверный API, внешняя CDN и сервисы Sites не требуются. При подключении домена обновите canonical, sitemap.xml и robots.txt в index.html/public, затем пересоберите сайт. На GitHub Pages домен также настраивается в Settings → Pages.

## Состав и проверки

Three.js загружается отдельно от интерфейса. Кнопка «Список проектов» переключает выставку на обычную страницу с теми же описаниями. При отсутствии WebGL список открывается автоматически. Для навигации доступны мышь, касания, стрелки клавиатуры и Escape; подробности открываются в диалогах с возвратом фокуса. На телефоне камера и расположение объектов адаптируются к экрану. Движение можно отключить; prefers-reduced-motion отключает его по умолчанию. Неактивная сцена не рисует кадры, а на мобильных частота ограничена примерно 30 кадрами в секунду.

Интерактивные эффекты — иллюстрации возможностей проектов, а не запущенные сборки игр или соединение с настоящим оборудованием. Telegram и ВКонтакте в блоках связи взяты из публичного README профиля GitHub.

Сведения об опыте предоставлены владельцем: 2,5 года коммерческой разработки по состоянию на сентябрь 2026. Описания проектов основаны на аудите исходников; отдельные проекты не объявляются полностью аппаратно проверенными или выпущенными на всех целевых платформах.

Изображения Danro и Danro Jump — материалы проектов; Wizard — используемые игровые ресурсы. Карточки инструментов содержат схемы и визуализации, а не скриншоты приложений. Существующие лицензии сторонних материалов сохранены в public/assets/licenses. Новая общая лицензия на собственный код не назначалась.
