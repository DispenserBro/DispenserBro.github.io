# Портфолио Данила Яроша

Портфолио открывается как интерактивная 3D-галерея на Three.js. Один проект показан крупно, соседние работы уходят в глубину. Настоящие скриншоты размещены на объёмных экранах, окружённых металлическими лентами. Проекты переключаются колесом, стрелками, кнопками и нажатием на экраны; запись работы можно запустить прямо в сцене. Сайт публикуется на GitHub Pages и переносится на любой статический хостинг.

## Разработка

Нужен Node.js 22.12+ или 24 LTS.

~~~sh
npm ci
npm run dev
~~~

## Сборка и публикация

~~~sh
npm run build
~~~

Готовый сайт находится в dist/ и автоматически копируется в docs/. В репозитории GitHub Pages настроен на ветку main, папку /docs. Для обновления выполните сборку, затем commit и push. Исходники, package-lock.json и готовая папка docs хранятся вместе; node_modules и dist в Git не включаются.

## Как редактировать

- src/projects.js — карточки, технологии, описания и ссылки на проекты.
- index.html — главная страница, сведения об авторе и контактные ссылки.
- src/style.css, src/polish.css и src/gallery.css — оформление и адаптивная компоновка.
- src/media.js — 29 скриншотов и восемь видеозаписей проектов, подписи и ограничения показанных сценариев.
- src/world.js — 3D-галерея, металлические ленты, камера, выбор работ и VideoTexture.
- public/assets/ — изображения и сведения о лицензиях.

## Перенос на другой хостинг

Выполните npm ci и npm run build, затем загрузите содержимое dist/ в публичную папку сайта. Node.js на сервере не нужен. Ресурсы используют относительные пути; серверный API, внешняя CDN и сервисы Sites не требуются. При подключении домена обновите canonical, sitemap.xml и robots.txt в index.html/public, затем пересоберите сайт. На GitHub Pages домен также настраивается в Settings → Pages.

## Состав и проверки

Three.js загружается отдельно от интерфейса. Кнопка «Все работы» переключает галерею на обычную страницу с теми же описаниями. При отсутствии WebGL список открывается автоматически. Для навигации доступны мышь, касания, стрелки клавиатуры и Escape; подробности открываются в диалогах с возвратом фокуса. На телефоне камера и расположение объектов адаптируются к экрану. Движение можно отключить; prefers-reduced-motion отключает его по умолчанию. Неактивная сцена не рисует кадры, а на мобильных частота ограничена примерно 30 кадрами в секунду.

В 3D-сцене показаны реальные записи проектов, а не запущенные сборки или соединение с оборудованием. Telegram и ВКонтакте в блоках связи взяты из публичного README профиля GitHub.

Сведения об опыте предоставлены владельцем: 2,5 года коммерческой разработки по состоянию на сентябрь 2026. Описания проектов основаны на аудите исходников; отдельные проекты не объявляются полностью аппаратно проверенными или выпущенными на всех целевых платформах.

Карточки и экраны моделей используют реальные скриншоты проектов, снятые 2 октября 2026. В описании каждого проекта есть галерея и видеозапись без звука. Снимки оптимизированы в WebP; ролики MP4/H.264 загружаются по нажатию в сцене или при открытии вкладки видео. При закрытии описания воспроизведение останавливается. Съёмка Plate Config App проходила без подключённой платы, Exchanger — с эмулятором оборудования; эти ограничения указаны в галереях. В Danro показана анимированная игровая сцена, в Danro Jump — автоматические прыжки и продвижение по уровню.

Тёмная композиция использует студийный свет, металлические поверхности и спокойный фон. Рендеринг приостанавливается в скрытой вкладке и при открытом диалоге, автоматическое движение можно отключить. Видео в сцене останавливается при смене проекта, режима или открытии описания. На мобильных ограничены частота и разрешение отрисовки.

При переработке изучены оригинальные сайты [Lusion](https://lusion.co/), [Dennis Snellenberg](https://dennissnellenberg.com/) и [Bruno Simon](https://bruno-simon.com/): крупный визуальный центр, типографика, пространственная навигация и небольшое число элементов в каждом состоянии. Реализация и композиция собственные. Существующие лицензии сторонних материалов сохранены в public/assets/licenses; новая общая лицензия на код не назначалась.
